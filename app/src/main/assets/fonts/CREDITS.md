# Manhwa lettering fonts

The `.ttf` files in this folder are the Vietnamese comic lettering fonts from the
**Font Truyện Tranh Teddy** pack by iCiel (Teddy), included so translated pages keep the
handwritten look of the original lettering instead of falling back to the phone's system font.

They were renamed to the role each one plays in the renderer:

| File here | Original file | Role |
|---|---|---|
| `manhwa_sans_regular.ttf` | `000BlahBlahUCiCiel-Regular.ttf` | dialogue, normal |
| `manhwa_sans_bold.ttf` | `000BlahBlahUCiCiel-Bold.ttf` | dialogue, emphatic |
| `manhwa_sans_italic.ttf` | `000BlahBlahUCiCiel-Italic.ttf` | dialogue, slanted |
| `manhwa_sans_bold_italic.ttf` | `000BlahBlahUCiCiel-BoldItalic.ttf` | dialogue, emphatic and slanted |
| `manhwa_sans_black.ttf` | `000HundredWattiCiel-Bold.ttf` | dialogue, shouted |
| `manhwa_serif_regular.ttf` | `000PiekosProiCiel-Regular.ttf` | narration |
| `manhwa_serif_italic.ttf` | `000PiekosProiCiel-Italic.ttf` | narration, slanted |
| `manhwa_display.ttf` | `000WhizBang-Roman.ttf` | shouts and short titles |

All of them cover the full Vietnamese alphabet with diacritics.

The fonts belong to their authors, not to this project. If you fork the app, keep this file and
the credit above with the fonts, and check the pack's own terms before republishing the APK.
